## The Name

**Always written as: aXantiq**

- Lowercase `a`, uppercase `X`, rest lowercase
- The X is rendered in Regular weight at 110% size in all brand assets — same stroke, just bigger
- Never: Axantiq, AXANTIQ, axantiq, AxantiQ
- Fallback (code/URLs): `axantiq` (all lowercase)

## Usage Guidelines

### Do

- Use the green logo on dark backgrounds (preferred)
- Maintain adequate spacing around the logo
- Use transparent versions for overlays
- Keep the X visually prominent

### Don't

- Stretch or distort the logo
- Change the font or letterforms
- Use low contrast color combinations
- Write the name with a lowercase x
