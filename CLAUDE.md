## Context & memory discipline (READ FIRST)

Memory is the system of record for this project — not your head, not a handoff doc.

- **Start of session:** read docs/memory/state.md (current epic + next steps), then the relevant docs/memory/{tech,decisions,playbooks}.md sections BEFORE deriving anything. Settled work is already captured — do NOT re-derive it.
- **End of session:** any artifact you produced or recovered — an audit, a spec, a decision, a scope, a "where does X live" answer — MUST be written to docs/memory/ (and repo/Linear where canonical) in the SAME session. Rewrite state.md before you stop.
- A NEXT-SESSION-*.md handoff doc is a convenience, NEVER the system of record; never strand one on an unmerged side branch.
- Before env/deploy/DB work: read docs/memory/tech.md. Repeated procedures: playbooks.md. Why things are the way they are: decisions.md.
